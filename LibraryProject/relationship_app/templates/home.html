Django Role-Based Access Control

Implementation of RBAC with Admin, Librarian, and Member roles

👑 Admin

Full system access and administration privileges.

  • Manage all users
  • System configuration
  • Access all features
📚 Librarian

Library management and operational access.

  • Manage book catalog
  • Process loans & returns
  • Handle reservations
👤 Member

Basic library access and personal features.

  • Browse books
  • Borrow books
  • View history
How to Test:
  1. Login with different user accounts
  2. Each role will see different dashboard options
  3. Access control is enforced via decorators
  4. Try accessing role-specific URLs directly
