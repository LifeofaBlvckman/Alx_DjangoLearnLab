# Advanced Features and Security - Custom User Model

This project implements a custom user model in Django for ALX Django Learning Lab.

## Features
- Custom User model with email authentication
- Required date_of_birth field (DateField)
- Optional profile_photo field (ImageField)
- Custom user manager
- Admin interface integration

## Verification
Run: python verify_alx.py

## Setup
1. Install: pip install -r requirements.txt
2. Migrate: python manage.py migrate
3. Run: python manage.py runserver
4. Admin: http://127.0.0.1:8000/admin/
