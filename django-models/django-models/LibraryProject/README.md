# LibraryProject - Django Introduction

## Project Overview
This Django project is part of the ALX Django Learn Lab introduction to Django framework.

## Setup Instructions

### 1. Install Django
```bash
pip3 install django
```

### 2. Navigate to Project Directory
```bash
cd ~/Alx_DjangoLearnLab/Introduction_to_Django/LibraryProject
```

### 3. Run Development Server
```bash
python3 manage.py runserver
```

### 4. Access Application
Open browser and visit: http://127.0.0.1:8000/

## Project Structure
- `manage.py` - Django command-line utility
- `LibraryProject/` - Main project package
  - `__init__.py` - Python package marker
  - `settings.py` - Project configuration
  - `urls.py` - URL routing
  - `wsgi.py` - WSGI application entry
  - `asgi.py` - ASGI application entry
